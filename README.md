# 🔷 NEXUS ECOSYSTEM v2.3
### O dinheiro que nasce do seu celular.

**Nó Gênesis #001 - Fundado em 10/11/2026 por Matheus em Santo André, SP**

O NEXUS não é um banco. É um ecossistema onde seu celular vira um Nó que minera, paga e guarda valor - mesmo sem internet.

---

## 💰 O que é o NEX?
**1 NEX = R$ 0,10**
Moeda do ecossistema. Minerada por simbiose, não por gasto de energia.

## 🏛️ Os Arcontes (Agentes)
| Arconte | Função |
| :--- | :--- |
| **NEXUS PRIME** | Cérebro Supremo - Supervisiona tudo |
| **PLUTARCH** | Banco - Carteira, conversão Real -> NEX, NEX Guardado |
| **VEGA** | Mineração por simbiose |
| **AEGIS** | Segurança - Trava offline 200 NEX, trava FOUNDER 5.000 NEX |
| **HERMES** | Dev - Escreve, testa e corrige código |
| **FENIX** | Resiliência - Se cair, renasce mais forte |

## 💸 NEX Pay - Offline
Pague com QR Code + Bluetooth, sem internet. Limite offline: 200 NEX.
Quando a internet volta, tudo sincroniza automaticamente.

## 📈 NEX Guardado
| Plano | Rendimento | Limite |
| :--- | :--- | :--- |
| **FOUNDER** | 2,5% ao dia | Até 5.000 NEX por pessoa |
| **EXPANSÃO** | 1,0% ao dia | Sem limite individual |
